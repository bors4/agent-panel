# Linux / macOS Rules

## Shell

- Use bash by default
- Use `sh` for POSIX-compatible scripts

## Common Commands

| Task | Command |
|------|---------|
| List files | `ls -la` |
| Find text | `grep -rn "text" *.js` |
| Check OS | `uname -a` |
| Environment | `$PATH` |

## Notes

- Paths are case-sensitive
- Use forward slashes `/` for all paths
